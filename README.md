💡 CodeWise: Scalable AI Code ExplainerIntroductionCodeWise is a high-performance, asynchronous web application designed to instantly generate comprehensive, documentation-style explanations for any code snippet or file.Built with a scalable Node.js backend and the Gemini API, CodeWise prioritizes speed and reliability by offloading time-consuming AI generation tasks to a background Job Queue (BullMQ/Redis). This ensures the user experience is always instant, never blocked by long-running processes.✨ Core FeaturesInstant Response (202 Accepted): Users receive immediate confirmation that their job is accepted, and their UI is not blocked while waiting 10-15 seconds for the AI.Asynchronous Job Queue: Utilizes BullMQ and Redis to decouple the API from the heavy processing (Gemini call), maximizing server health and scalability.Structured Documentation: Generates robust, multi-section documentation (Overview, Logic Flow, Complexity, Improvements) based on a forced JSON schema for clean UI integration.Secure Sharing: Allows authenticated users to generate unique, public, read-only links for any generated explanation.Robust Security: Implements user authentication (ProtectedRoutes), IP-based Rate Limiting for high-cost AI endpoints, and input validation to protect API quotas.⚙️ Architecture: The Job Queue ModelThis application uses a Producer/Consumer architecture to guarantee high concurrency:The API (Producer): Receives a user request, creates a PENDING record in PostgreSQL, and immediately adds a job to the Redis queue. It returns a 202 Accepted response. (Time: ~50ms)The Worker (Consumer): Runs as a separate Node.js process. It pulls the job from Redis, executes the slow 10-15 second Gemini API call, and updates the database record to COMPLETED or FAILED.The Frontend: Polls the database status using the instant ID until the status flips to COMPLETED.🛠️ Tech StackCategoryTechnologyPurposeMonorepoNext.js (Frontend), Node.js/Express (API)Full-stack environment for separate apps.AIGemini API (gemini-2.5-flash)Core explanation and commenting engine.DatabasePostgreSQL, Prisma ORMPersistent data storage, type safety.QueueingBullMQRobust job queue management library for Node.js.Message BrokerRedis (via Docker)Fast, in-memory store for the job queue.Auth/SecurityJWT, ProtectedRoute Middleware, express-rate-limitUser authentication, permission management, and API protection.🚀 Getting StartedFollow these steps to set up and run the full backend environment.PrerequisitesNode.js (LTS version)Docker Desktop (Required to run Redis)A Gemini API Key (set in your .env file).Installation & SetupClone the Repository:git clone [your-repo-link]
cd codewise
npm install
Configure Environment:Create a .env file in the root of your project and fill in your keys:# Gemini AI
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"

# PostgreSQL Database (e.g., Neon URL)
DATABASE_URL="postgresql://user:password@host:port/dbname?sslmode=require" 
Start Redis (The Queue Broker):Open your terminal (outside the project folder is fine) and run the Docker command:docker run -p 6379:6379 -d redis/redis-stack-server:latest
This starts the Redis server that BullMQ will use.Setup Database Schema:Apply the database schema and migrations:npx prisma migrate dev --name init_database_schema
🏃 Running the Application (Dual Process)You must run two separate processes for the application to function: the API and the Background Worker.1. Start the API (The Waiter)This process handles HTTP requests and puts jobs into the queue.# In Terminal 1
npm run dev
2. Start the Worker (The Chef)This process listens to the queue and executes the expensive AI generation.# In Terminal 2
node worker.js
Testing the ScalabilityWith both processes running, use Postman to hit the POST /api/explainations endpoint.Observe the API terminal: It will respond instantly (202 Accepted).Observe the Worker terminal: It will begin the 10-15 second processing for the job, confirming your asynchronous system is active.
